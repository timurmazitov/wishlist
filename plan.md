# План реализации Birthday Wishlist

## 1. Структура проекта

```
wishlist/
├── server/                          # Node.js API сервер
│   ├── server.js                    # Точка входа сервера
│   ├── database.js                  # SQLite база данных
│   ├── routes/
│   │   ├── gifts.js                 # Маршруты для подарков
│   │   ├── selections.js            # Маршруты для выбора подарков
│   │   └── services/
│   │       ├── mailer.js            # Отправка email
│   └── package.json                 # Зависимости сервера
├── client/                          # Статический фронтенд
│   ├── index.html                   # Главная страница (3 экрана)
│   ├── css/
│   │   └── style.css                # Кастомные стили
│   └── js/
│       └── app.js                   # Вся логика приложения
├── data/                            # База данных
│   └── wishlist.db                  # SQLite файл
└── .env                             # Конфигурация (email)
```

## 3. База данных (SQLite)

### Таблица `guests`

| Колонка        | Тип        | Описание         |
| -------------- | ---------- | ---------------- |
| id             | INTEGER PK | Уникальный ID    |
| name           | TEXT UNIQUE| Имя гостя        |

### Таблица `gifts`

| Колонка       | Тип      | Описание                          |
| ------------- | -------- | --------------------------------- |
| id            | INTEGER PK | Уникальный ID                  |
| name          | TEXT     | Название подарка                  |
| description   | TEXT     | Краткое описание                  |
| image_path    | TEXT     | Путь к картинке (относительный)   |
| price         | REAL     | Примерная стоимость               |
| links         | TEXT     | JSON-массив ссылок на покупки     |
| total_needed  | INTEGER  | Требуемое количество, 0 = неограниченно |

### Таблица `selections`

| Колонка       | Тип      | Описание                    |
| ------------- | -------- | --------------------------- |
| id            | INTEGER PK | Уникальный ID           |
| guest_id      | INTEGER  | ID гостя (FK на guests.id)  |
| gift_id       | INTEGER  | ID подарка (FK на gifts.id) |
| quantity      | INTEGER  | Количество выбранных единиц |
| created_at    | DATETIME | Время создания записи       |

## 4. API маршруты

### Подарки
- `GET /api/gifts` — список всех подарков
- `GET /api/gifts/:id` — детали одного подарка

### Выбор подарков
- `POST /api/selections` — `{ guest_id, gift_id, quantity }` — сохранить выбор
- `GET /api/selections?guest_id=X` — получить все выбранные подарки гостя
- `DELETE /api/selections?guest_id=X` — очистить все выборки гостя

### Отправка (сервисы)
- `POST /api/send-email` — `{ guest_id, selections[] }` → отправка на email через Nodemailer

## 5. Экраны приложения

### Экран 1 — Выбор гостя
- Заголовок: «Добро пожаловать!»
- Выпадающий список `<select>` с именами гостей
- Кнопка «Выбрать подарок»
- Если в cookies есть `selected_guest_id` — редирект на Экран 2

### Экран 2 — Выбор подарков
- Шапка: кнопка «Начать заново» (справа, красный цвет)
- Заголовок: «Выберите подарки»
- Список карточек подарков:
  - Название, картинка, цена
  - Кнопки «−» и «+» для изменения количества
  - Клик по карточке — открытие модального окна с деталями
- Кнопка «Очистить всё» (сбросить все выборы)
- Футер: кнопка «Сохранить» + текстовая подпись «Выбрано: X подарков, на сумму Y ₽»
- **Важно:** При выборе подарка проверять, что общее количество подарков не превышает `total_needed` (сумма по всем гостям)

### Экран 3 — Сохранённый список
- Шапка: как на Экране 2 (кнопка «Начать заново» справа)
- Заголовок: «Ваш список подарков»
- Список выбранных подарков с количеством
- Кнопка «Назад» для редактирования

**Кнопки отправки (если контакт указан):**
- Если у гостя есть email → кнопка «Отправить на email»
- Кнопки отображаются только если соответствующий контакт есть

### Модальное окно — Детали подарка
- Картинка подарка
- Название
- Описание
- Примерная стоимость
- Список ссылок для покупки
- Кнопка «Закрыть»

## 7. Мобильная адаптация

- viewport: `width=device-width, initial-scale=1.0`
- Базовые стили для 1080×2400, 402 PPI (реальные размеры ~360×800 CSS-пикселей)
- Размер шрифта: 14px база, крупные кнопки (min-height: 44px)
- Карточки подарков: full-width с padding
- Touch-friendly: отступы между элементами ≥ 12px
- Max-width: 480px для основного контента

## 8. Отправка email

- Используется `nodemailer`
- Настройки в `.env`: `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_USER`, `EMAIL_PASS`
- Формат: HTML-письмо с таблицей подарков
- Можно использовать любой SMTP
