Верстка должна быть максимально простой и лаконичной. Используй TailWind CSS и минимум javascript, никаких сложных фреймворков и анимаций. Если необходима база данных, то используй самую простую и распространённую. Сайт необходимо разворачивать на максимальном количестве самых простых хостингов.

При первом открытии пользователь выбирает из выпадающего списка предустановленных приглашённых лиц себя, нажимает кнопку «Выбрать подарок».
Выбранный ID пользователя сохраняется в cookies, чтобы в следующий раз пользователя сразу перенаправлять на следующий экран, чтобы у него не было необходимости каждый раз выбирать себя.
На втором экране отображается список подарков. Требуемое количество конкретного подарка с кнопками плюс-минус, чтобы можно было выбрать нужное количество подарков для добавления в свой список. Должна быть возможность очистки сразу всех выбранных подарков.
Вверху, справа отображается кнопка «Начать заново». Если её нажать, то пользователя перенаправлять на страницу выбора пользователей, ID пользователя из cookies очищать.
Внизу страницы Второго экрана должна быть кнопка «Сохранить» Также количество выбранных подарков.
После нажатия на кнопку «сохранить» пользователя отображается третий экран, в котором есть такая же шапка, как и на втором экране, и отображается итоговый список выбранных им подарков. 

На втором экране должна быть возможность открытия подробной информации по каждому из подарков. При этом отображается детальная информация о подарке, отображается картинка, краткое описание и две-три ссылки на сайты, где можно его приобрести. а также примерная стоимость.
